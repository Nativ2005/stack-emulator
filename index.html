📚 What is the stack?

A part of memory that works like a pile of plates: you only add (push) or remove (pop) at the top. Last in, first out.

⬇ It grows downward

On x86 the top of the stack has the lowest address. push makes ESP smaller, pop makes it bigger. In the view, the newest value is at the bottom, next to the ESP arrow.

🧭 Three key registers

ESP points at the top of the stack.
EBP is the fixed anchor of the current function.
EIP is the address of the next instruction.

📞 call & ret

call f pushes the return address (where to come back) and jumps to f. ret pops it and jumps back. Overwrite it and the program goes somewhere else!

🧱 One function's frame

[ebp-4]   local variable

    Syntax
    
          
      
            
    • Registers: eax ebx ecx edx esi edi ebp esp, bytes al ah bl …
      • 
            
    • Numbers: 42, -8, 0x1f, 1fh, 0b101, 'A'
      • 
            
    • Memory: [ebp-8], [esp+4], [eax+ecx*4+8]
      • 
            
    • Size: dword [ebp-4] / byte ptr [edi] (default dword)
      • 
            
    • Labels: name:, local .loop:; execution starts at main
      • 
            
    • Comments: ; or #
      • 
            
    • Only the stack () is mapped memory. Anything else faults.
      • 
            
    • Keys: Ctrl+Enter assemble, → step, ← back.
